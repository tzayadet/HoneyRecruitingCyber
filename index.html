Honey Recruiting Cyber

A cybersecurity recruitment honeypot prototype that simulates a technical community. Participants interact with different bot profiles while the application analyses technical vocabulary, estimates knowledge levels and records interaction metrics.

Explore source codeTechnical documentation
Deployment note. This GitHub Pages site is the project overview. The interactive chat and analytics require the Flask application, its database and a running Python backend; GitHub Pages does not execute that server-side code.

Project components

01 / INTERACTION

Technical discussion simulator

A chat interface with configurable bot personas and a simulated cybersecurity community.

02 / ASSESSMENT

Knowledge signals

Keyword analysis and scoring logic to estimate technical familiarity from conversation content.

03 / OBSERVABILITY

Recruitment analytics

Session activity, user scores and dashboard views for reviewing interaction patterns.

Architecture & stack

Python application with Flask routes, SQLAlchemy data models and a PostgreSQL-compatible database configuration. The interface uses Jinja templates, Bootstrap, vanilla JavaScript and Chart.js.
